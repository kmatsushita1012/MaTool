# 地図Root・紹介Sheet 受け入れ確認

更新日: 2026-10-25

実機能をSimulatorで操作して確認し、各項目の結果・再現条件・証跡をここに記録する。テストスイートはユーザーのOKが出るまで実行しない。

## 地図・設定・管理者

- [ ] 未ログインで起動すると地図が表示される。
- [ ] 地図右上の `gearshape` から設定を開ける。
- [ ] 設定から管理者ログインを開ける。
- [ ] ログイン成功時、設定画面を階層から置換して管理者画面を表示する。
- [ ] 管理者画面から戻ると地図に戻る。
- [ ] ログイン済みで地図の `gearshape` を押すと管理者画面を開ける。
- [ ] 管理者画面から設定を開き、戻ると管理者画面に戻る。
- [ ] ログアウト後は管理者用の画面・Navigation状態が残らず、地図に戻る。
- [ ] ログイン済みで前回の主要画面が地図なら地図を復元する。
- [ ] ログイン済みで前回の主要画面が管理者なら、地図を基点に管理者を復元する。
- [ ] 未ログインでは保存状態にかかわらず地図を表示する。

## 紹介Sheet

- [ ] 地図右上の紹介ボタンから祭全体の紹介Sheetを開く。
- [ ] 祭全体表示中は祭全体の紹介を最初に表示する。
- [x] 町選択中は該当する町紹介をStackの最下段としてSheetを開く。
- [ ] 屋台アノテーションから該当する町紹介をStackの最下段としてSheetを開く。
- [x] Sheetを町紹介から開いた場合、祭名ボタンで祭紹介をpushする（町紹介へpopしない）。
- [x] 祭紹介の「紹介」と「町一覧」を切り替えられる。
- [x] 町一覧はGroup名、続いて町名の順で並ぶ。
- [x] 町一覧から町紹介をpushできる。
- [x] 町紹介上部のボタンはアイコンではなく祭名のテキストで表示する。
- [x] Stack最下段の左上 `cancellationAction` に常に `xmark` の閉じるボタンがある。
- [ ] 町紹介および祭紹介への遷移は対象画像の読み込み完了後に行う（最初のSheet表示を含む）。
- [ ] 紹介画面のnavigation barはhard scroll-edge styleで表示する。
- [x] 地図のトーストは上部safeAreaInset内でPicker群の下に16pt間隔で表示する。
- [x] Sheetは半分の高さから開き、祭紹介・町紹介の画像とスクロール内容が要件どおり表示される。
- [x] Sheetを閉じても地図の町・期間選択を維持する。
- [ ] 町切り替え後も選択期間を保持し、町Pickerの順序を維持する。
- [x] ぼかし画像は背景に表示し、非ぼかし画像はスクロール先頭に16pt inset・角丸で表示する。非ぼかし画像は固定高を使わず、利用可能幅にアスペクト比を保って表示する。
- [x] 町紹介に「現在地とルート」ボタンが表示されない。

## 余興カード

- [ ] 説明文がないカードは高さを固定せず、内容に合わせて表示する。
- [x] 短い説明文は「もっと読む」を出さず、内容に合わせて表示する。
- [ ] 長い説明文は高さ160ptで省略し、「もっと読む」を表示する。
- [ ] 「もっと読む」を押すとカードが全文まで伸びる。
- [x] 同じ行のカードは、内容量が異なっても高さが揃う。
- [ ] 展開したカードと同じ行の隣のカードも高さが揃う。
